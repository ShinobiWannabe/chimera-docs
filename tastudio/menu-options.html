TAStudio

Menu Options

What it is

The TAStudio menu bar has five menus and a Hide button. Saving and closing a project are done in the Chimera File menu, not here. This page also describes the right-click menu of the piano roll and the TAStudio settings window.

How to use it

Click a menu name to open it. Many Edit items work on the rows you have selected, so select rows in the piano roll first. Items that do not apply right now are greyed out. The hotkeys for these items are listed on the TAStudio tab of the Hotkeys page.

Edit menu

ItemWhat it does
Undo, RedoGo back or forward through your edits.
Show Undo HistoryOpens a window that lists your edits.
Selection Undo, Selection RedoGo back or forward through changes to which rows are selected.
DeselectClears the selection.
Select between MarkersSelects every row between the two markers around the selection.
Select AllSelects every row.
Reselect ClipboardSelects the rows that were last copied.
Go to Frame...Asks for a frame number and seeks to it.
Copy, CutCopy or cut the input of the selected rows to the clipboard.
PasteWrites copied input over the rows from the first selected row.
Paste InsertInserts copied input at the first selected row and moves the later rows down.
ClearRemoves the pressed buttons from the selected rows. The rows stay.
DeleteRemoves the selected rows from the movie.
InsertInserts empty rows at the selection, as many as are selected.
Insert # of FramesAsks how many empty rows to insert.
CloneRepeats the selected rows once right after the selection.
Clone # TimesAsks how many times to repeat the selected rows.
Truncate MovieCuts off the movie after the last selected row.
Clear GreenzoneThrows away the saved states. See Greenzone.
State History Integrity CheckReplays the movie and checks that it matches the saved states. It reports Integrity Check passed, or tells you which frames are bad and offers to save the state.
Save Selection to MacroSaves the selected input as a macro file.
Place Macro at SelectionPuts a macro file into the movie at the selection.
Recent MacrosLists macro files you used lately.

Metadata menu

ItemWhat it does
Header...Opens the movie header, which holds details such as the author and the core.
Comments...Opens a window for free text notes saved with the movie.
Subtitles...Opens a window for text that shows over the picture at chosen frames.

Settings menu

ItemWhat it does
Open settings...Opens the TAStudio settings window, described below.

Columns menu

The Columns menu lists every button column with a tick for each column that is shown. Tick or untick to show or hide a column in the active roll. If you have more than one roll, the top line says which roll is current. See Split Input Rolls.

Window menu

ItemWhat it does
Move with Main WindowWhen ticked, dragging the Chimera window moves TAStudio along and keeps its place beside it. Dragging TAStudio moves only TAStudio. Hold Shift to move the main window without TAStudio.

<< Hide

The Hide button at the right end of the menu bar hides the TAStudio window. Press Show TAStudio >> in the Chimera menu bar to bring it back.

Piano roll right-click menu

A right click on a row opens this menu.

ItemWhat it does
Set MarkersPuts a marker on each selected row. TAStudio asks first if you select more than 50 rows.
Set Marker with TextPuts a marker on the row and asks for a name.
Remove MarkersRemoves the markers on the selected rows.
Deselect, Select between MarkersSame as in the Edit menu.
Clear GreenzoneThrows away the saved states.
Cancel SeekStops a seek that is in progress.
Copy, Paste, Paste Insert, Cut, Clear, DeleteSame as in the Edit menu.
Insert, Insert # of Frames, Clone, Clone # Times, Truncate MovieSame as in the Edit menu.
BranchAdds a branch at the current frame. It shows only when you right-click the row the game is on.

Right-clicking a column header opens a different menu. See Split Input Rolls.

Settings window

The settings window has six tabs. Some options are saved with the movie and some with your config.

Appearance tab

OptionWhat it does
Lag frames to hideHow many lag frames in a row to hide from the piano roll. A lag frame is a frame in which the game did not read the controls.
Hide "was lag" framesHides frames that were lag frames.
Rotate input rollTurns the piano roll on its side, with frames across and buttons down.
Set Font, Set ColorsChange the font and the colors of the piano roll.
Denote markers with color or iconsMarks marker rows with a color on the frame column, with an icon, or both.
Denote states with background color or iconsMarks rows that have a saved state with a background color, with an icon, or both.

Autosave tab

OptionWhat it does
Autosave frequencySeconds between automatic saves. 0 turns autosave off.
When manually saving, also save .backupMakes a backup file each time you save.
Save as .backup (no greenzone)Autosave writes a backup file without the greenzone, so it is quick.

Savestates tab

OptionWhat it does
Management strategyChooses how TAStudio decides which states to keep. Each movie holds its own settings.
Use these settings as defaultMakes the current settings the default for new movies.
Use default settingsLoads the default settings into this movie.

Paint Patterns tab

OptionWhat it does
Choose patternHold keeps the button pressed. Auto-Fire presses and releases it over and over. Custom uses a pattern you write.
Use pattern for paintingAlways, Auto-Fire columns only, or Never. It decides when dragging in the piano roll follows the pattern.
Custom patterns (per movie)A list of Count and Value pairs for each button. Insert and Delete edit the list. Account for lag frames makes the pattern skip lag frames.

Misc tab

OptionWhat it does
Old control scheme for branchesUses the older way of working with branches.
Load branch by double clickingA double click on a branch loads it.
Rewind step, Fast rewind stepHow many frames one rewind and one fast rewind go back.
Bind markers to inputMarkers move with the rows when you insert or delete rows.
Include frame numbers when copying inputCopied text carries the frame numbers.
Max Undo CountHow many edits can be undone.
Automatically pause at end of moviePauses when playback reaches the last frame.
Markers keep states by defaultKeeps a saved state at each marker.

Input Roll tab

OptionWhat it does
Scroll to cursor methodWhere the current row goes when the view follows it. Choose center, bottom, top or view.
When following cursor, scroll at every frameScrolls on every frame and not only when the row leaves the view.
Wheel scroll speedHow many frames one notch of the mouse wheel moves.
Allow editing hidden columnsLets Clear, record and paste change columns that are hidden.

Apply saves the changes and keeps the window open. Cancel closes it without saving.

What it shows

The menus show only the items above. Hotkeys appear beside many items. The status bar at the bottom of the window shows messages about saving, seeking and the current state.
