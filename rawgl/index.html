Quickstart

System Another World

Quickstart

  1. Put the rawgl core file (it ends in .chimeraCore) in the Cores folder next to Chimera.exe.
  2. Open the File menu and choose New Chimera Project.
  3. Page 1. Choose rawgl in the Core list and pick your game version in the System list, then press Next.
  4. Page 2. Change settings if you want to. The defaults work for most games. Press Next, or Create if that is what the button says.
  5. Page 3. Give each file in the list, then press Create. The files come from hardware or game copies you own.
  6. Chimera opens the new project in TAStudio (its input editor) at the first frame.

You can also drag a game file onto the Chimera window. The wizard then opens with the core and the file already chosen.

For more detail, see the Full Guide.
