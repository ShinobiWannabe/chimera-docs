About this data

This core has one system and no machine list. The row comes from 'systemId', 'systemNames', the shared 'input' and 'extensions', and the 'video' block. So Machine value and Label are empty. If a machine leaves out its controller, picture size or file types, the shared value is used. Buttons and Axes count the rows in the Inputs section.
