Lua

Basics

A very short tour of the Lua language, just enough to read and write Chimera scripts. It follows Sections 2 and 3 of the Lua 5.5 manual. Each part names the manual section it comes from.

Before you begin

  • Lua is a small scripting language. A script is a text file that ends in .lua. Chimera runs scripts from the Lua Console, which is described on the Lua Console page.
  • Chimera runs Lua 5.4. The 5.5 manual is almost the same for what is shown here. Two things from 5.5 do not work in Chimera. These are the global keyword and read-only loop variables. Avoid changing a loop variable inside its loop so a script works on both.
  • Every piece of code on these pages follows the LuaRocks Lua Style Guide. The rules used most are listed below.
  • Chimera adds its own functions to Lua, such as console.log and emu.frameadvance. They are used here and listed on the Basic Examples page.
Style ruleWhat it means
IndentThree spaces. No tabs.
Namessnake_case for variables and functions. UPPER_CASE only for constants.
StringsDouble quotes. Single quotes only when the text holds a double quote.
SemicolonsNot used.
VariablesAlways local, declared as late as possible in the smallest scope.
FunctionsWrite local function name(). No space between a function name and its parentheses.
SpacingA space after commas and around operators, except for ... A space after -- in comments.
Yes or no checksNames of functions that answer yes or no start with is_. Test a value with if name then, not if name ~= nil then.

Your first script

A script that does not loop runs once and stops. This one writes a line to the Output box of the Lua Console.

console.log("Hello from Lua")

To work with a running game, a script loops once for each frame. A frame is one picture the game draws. emu.frameadvance() tells Chimera to run the game for one frame and then come back. Without it the loop never lets the game move and Chimera stops responding.

while true do
   gui.text(10, 10, "Frame " .. emu.framecount())
   emu.frameadvance()
end

Values and types (manual 2.1)

A variable has no type. Its value does. Lua has eight types.

TypeExampleNotes
nilnilMeans no value. A variable that was never set is nil.
booleantrue falseOnly nil and false count as false in a test. The number 0 and the empty text are true.
number42 3.5 0xFFIntegers and floats are both numbers. An integer that gets too big wraps around.
string"text"A fixed sequence of bytes. A string cannot be changed, a new one is made instead.
functionprintFunctions are values. They can be stored, passed and returned.
table{1, 2, 3}The only way to group data. It is described below.
userdataobjects from ChimeraValues made outside Lua. A script rarely meets one.
threadcoroutinesA separate line of execution. See the Coroutines part below.
local lives = 3 -- integer
local ratio = 0.75 -- float
local name = "Mario" -- string
local is_alive = true -- boolean
local nothing = nil -- no value
console.log(type(lives), type(name), type(nothing))

Tables, functions and userdata are passed by reference. Two variables can point at the same table.

Variables and scope (manual 2.2 and 3.2)

  • A variable made with local exists only in the block where it is declared. A block is the code between do and end, or in a function, loop or if.
  • A name that is not declared local is a global. Globals are shared by the whole script and are slower, so avoid them.
  • A function can use the local variables around it. This is called a closure.
local score = 10

do
   local score = 99 -- a new variable that hides the first one
   console.log(score) -- 99
end

console.log(score) -- 10

Lexical conventions (manual 3.1)

  • Lua is case sensitive. Lives and lives are different names.
  • A comment starts with -- and runs to the end of the line. A long comment sits between --[[ and ]].
  • The reserved words are and, break, do, else, elseif, end, false, for, function, goto, if, in, local, nil, not, or, repeat, return, then, true, until, while. A name cannot be one of them.
  • A string sits between double quotes or single quotes. A backslash starts an escape such as \n for a new line. Text between [[ and ]] is taken as it is.
  • Numbers can be written in hex with 0x and can have a decimal point or an exponent.
-- a one line comment
--[[ a comment
     over several lines ]]
local message = "Line one\nLine two"
local raw = [[Line one
Line two]]
local mask = 0xFF

Statements (manual 3.3)

Assignment

Several variables can be set in one statement. Every value on the right is worked out first, so two variables can be swapped.

local x, y = 10, 20
x, y = y, x
local first, second = 1
-- second is nil because no value was given

if

local lives = mainmemory.read_u8(0x0359)

if lives == 0 then
   console.log("Game over")
elseif lives == 1 then
   console.log("Last life")
else
   console.log("Lives left " .. lives)
end

Loops

LoopUse it to
whileRepeat while a test is true. The test is made before each pass.
repeat ... untilRepeat until a test is true. The body always runs once.
numeric forCount from a start to an end by a step. The end is included.
generic forWalk through a table with ipairs or pairs.
for i = 1, 3 do
   console.log("Pass " .. i)
end

for i = 10, 0, -5 do
   console.log(i) -- 10, 5, 0
end

local buttons = {"A", "B", "Start"}
for index, name in ipairs(buttons) do
   console.log(index, name)
end

local count = 0
while count < 3 do
   count = count + 1
end

break leaves the nearest loop. Lua has no continue statement. The usual way is a goto to a label at the end of the loop body.

for i = 1, 10 do
   if i % 2 == 0 then
      goto continue
   end
   console.log(i) -- only odd numbers
   ::continue::
end

Constants and closing variables

A local can carry an attribute in angle brackets. <const> makes it read only. <close> runs the value's __close method when the variable goes out of scope. It is rarely needed in game scripts.

local max_lives <const> = 5

Style note. The guide asks for UPPER_CASE only for constants, so a fixed value that is used in many places can be written local MAX_LIVES <const> = 5.

Expressions (manual 3.4)

GroupOperatorsNotes
Arithmetic+ - * / // % ^/ always gives a float. // divides and rounds down. % is the remainder. ^ is the power.
Comparison== ~= < <= > >=~= means not equal. Values of different types are never equal, so 1 == "1" is false.
Logicand or notand and or stop early and return one of their operands. not always gives true or false.
Join text..Joins two strings. A number is turned into text.
Length#The number of items in a list or characters in a string.
Bits& | ~ << >>And, or, exclusive or, shift left and shift right. ~ alone is not. Chimera also has a bit library, shown on the Basic Examples page.

Operators run in a fixed order. From first to last they are ^, then unary operators, then * / // %, then + -, then .., then the shifts, then &, ~ and | for bits, then comparisons, then and, then or. Use brackets when unsure.

local lives = nil
local shown = lives or 3 -- 3, a default value
local text = "Score " .. 150 -- "Score 150"
local half = 7 // 2 -- 3
local ratio = 7 / 2 -- 3.5
local both = (lives == nil) and "empty" or "set"
local size = #"Chimera" -- 7

Avoid x and y or z when y can be nil or false. In that case the result is wrong. Use an if block instead.

Tables (manual 3.4.9)

A table holds many values under keys. A key can be a number or a text. A table used as a list has the keys 1, 2, 3 and so on. Lists start at 1. Some Chimera functions return lists that start at 0. Their first item is not counted by #, so loop over them with a number range.

local player = {
   name = "Mario",
   lives = 3,
   position = {x = 120, y = 64},
}

console.log(player.name, player["lives"], player.position.x)
player.lives = player.lives - 1

local frames = {10, 20, 30}
table.insert(frames, 40) -- add to the end
table.remove(frames, 1) -- take out the first
console.log(#frames) -- 3

for key, value in pairs(player) do
   console.log(key, value)
end

The style guide asks for a comma after every field, including the last, and the plain key = value form when the name is a valid identifier.

Functions (manual 3.4.10 and 3.4.11)

A function can take any number of values and return any number of values. A missing argument is nil and an extra one is ignored.

local function clamp(value, low, high)
   if value < low then return low end
   if value > high then return high end
   return value
end

local function min_and_max(first, second)
   if first < second then
      return first, second
   end
   return second, first
end

local low, high = min_and_max(9, 4)
console.log(clamp(300, 0, 255), low, high)

Three more forms are common.

  • Extra arguments. Three dots collect them. {...} turns them into a table.
  • Methods. A colon passes the object as the first argument, named self. object:name(1) is the same as object.name(object, 1).
  • Calls with one argument. A text or table can be written without brackets. The style guide allows this only for a table that spans several lines. Use brackets for a single text.
local function sum(...)
   local total = 0
   for _, value in ipairs({...}) do
      total = total + value
   end
   return total
end

local function make_counter()
   local count = 0
   return function()
      count = count + 1
      return count
   end
end

local next_id = make_counter()
console.log(sum(1, 2, 3), next_id(), next_id())

Errors (manual 2.3)

error stops the script with a message. assert does the same when its first argument is false or nil. pcall runs a function and catches an error instead of stopping. When an error is not caught, Chimera prints it in the Output box and stops that script.

local function read_score(path)
   local file, err = io.open(path, "r")
   if not file then
      return nil, err
   end
   local score = tonumber(file:read("l"))
   file:close()
   return score
end

local ok, message = pcall(function()
   error("something went wrong")
end)
console.log(ok, message)

The style guide asks that a failure which can be expected, such as a missing file, returns nil and a message. A mistake in how a function is used raises an error.

Metatables, coroutines and garbage collection (manual 2.4 to 2.6)

These are rarely needed in game scripts, so each gets only a short note.

  • Metatables change how a table behaves. For example __index supplies a value for a missing key. Chimera tables from the API do not need them.
  • Coroutines are functions that can pause and carry on later. They are a good way to write a sequence of steps that spans many frames.
  • Garbage collection frees memory that nothing uses any more. It is automatic. Set a variable to nil to let go of a large table.
local defaults = {speed = 1}
local settings = setmetatable({}, {__index = defaults})
console.log(settings.speed) -- 1, taken from defaults

local steps = coroutine.wrap(function()
   console.log("step one")
   coroutine.yield()
   console.log("step two")
end)

steps() -- prints step one
steps() -- prints step two

To spread a sequence over frames, call steps() each frame and let the script call emu.frameadvance() between the steps.

Handy library functions

Lua ships with small libraries for text, tables and numbers. These are the ones scripts use most.

FunctionWhat it doesExample
string.formatBuilds text from a pattern. %d is a whole number, %s is text, %x is hex, %.2f is a decimal.string.format("%04X", 255) gives 00FF
string.subTakes part of a text. Positions start at 1.string.sub("Chimera", 1, 4) gives Chim
tostring, tonumberConverts between numbers and text. tonumber gives nil when the text is not a number.tonumber("12") gives 12
table.concatJoins a list of texts with a separator.table.concat({"a", "b"}, ", ")
table.insert, table.removeAdds to or takes out of a list.table.insert(list, value)
math.floor, math.max, math.minRound down, and pick the larger or smaller number.math.floor(3.7) gives 3
io.openOpens a file. See Reading and writing files in the Basic Examples.io.open("log.txt", "w")
