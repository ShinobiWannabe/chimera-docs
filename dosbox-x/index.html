DOSBox-X

Quickstart

System MS-DOS

Quickstart

  1. Put the DOSBox-X core file (it ends in .chimeraCore) in the Cores folder next to Chimera.exe.
  2. Open the File menu and choose New Chimera Project.
  3. Page 1. Choose DOSBox-X in the Core list, then press Next.
  4. Page 2. Press Add under Floppy disks or CD-ROMs or Hard disk or Configuration file and pick your game files. At least one file is needed. Press Next.
  5. Page 3. Change settings if you want to. The defaults work for most games. Press Next, or Create if that is what the button says.
  6. Page 4 only appears when your choices need firmware files. Give each file in the list, then press Create.
  7. Chimera opens the new project in TAStudio (its input editor) at the first frame.

You can also drag a game file onto the Chimera window. The wizard then opens with the core and the file already chosen.

Before you begin

  • A core is the package that holds an emulator. This page uses the DOSBox-X core, which runs MS-DOS. You get it from the Releases page of the chimera-core-dosbox-x repository on GitHub. In Chimera, the File menu entry Core Manager lists the cores you have installed.
  • A project is what Chimera creates for one game. It records the names and SHA1 values of your files, your settings and your recorded inputs. A SHA1 is a fingerprint of a file's contents. A project never records where your files are on disk.
  • Firmware means system files copied from real hardware or from a game, such as a BIOS (the built-in startup program of a console or computer). Chimera does not include any.
  • Nothing is saved to disk when you press Create. The project stays in memory until you choose Save Project, which asks where to put it.
  • A movie is a recording of the inputs you press. It plays back the same way each time.
  • BizHawk is another emulator program. Some cores began as parts of it.
  • A frame is one picture the game draws. A game draws many of them each second.

Buttons on every page

ButtonWhat it does
BackReturns to the page before. It is greyed out on Page 1. Pages that do not apply are skipped. Your answers are kept.
NextGoes to the next page. On the last page it is called Create. If something is missing, a red message at the bottom left says what.

Page 1 Choose the core

The first page asks you to pick a core, either an emulator or a game. Everything on the later pages depends on this choice.

OptionWhat it does
KindEmulator or Game. It decides which cores the Core list shows. DOSBox-X is an emulator. The wizard opens on the kind you used last, when you have cores of that kind installed.
CoreLists the installed cores of that kind. Each line shows the core name, its version date and the systems it runs. Choose the DOSBox-X line. If you have two builds of one core installed, the line also shows the first eight characters of the package's fingerprint in square brackets.
SystemNames the machine to emulate. DOSBox-X has one, MS-DOS, so the box is greyed out.
RendererChooses how the picture is drawn, for cores that offer a choice. DOSBox-X draws one way, so the box is greyed out and shows Software (Native).

A link at the bottom takes you to the Chimera issue page, for reporting problems and asking for features. If no core is installed, Next shows a message asking you to pick one.

Page 2 Add your files

This page asks for the game files and other data. The core decides what appears here. DOSBox-X shows 4 groups of files. Hover over a group to see the core's own help text.

GroupHow manyFile typesWhat it is for
Floppy disksAny number.img, .ima, .xdf, .fdi, .hdm, .nfd, .d88, .dcpFloppy disk images (.img, .ima, .xdf, .fdi, .hdm, .nfd, .d88 and PC-98 .dcp dumps). The first one is in drive A when the machine starts. The order here is the order the Previous, Next and Swap Floppy Disk inputs go through.
CD-ROMsAny number.iso, .cueCD-ROM images. Each is a plain .iso file, or a .cue file whose track files join the project automatically. The first one is in drive D when the machine starts. The order here is the order the Previous, Next and Swap CDROM inputs go through.
Hard diskAt most one.hdd, .img, .hdiA raw hard disk image, or a PC-98 .hdi image (whose header gives the disk's layout). It becomes drive C and can be written to. What is written stays for the session and can be exported as save data, and an exported image can be given here to continue from it. With no image, the Mount Formatted Hard Disk Drive setting can provide an empty disk.
Configuration fileAt most one.confExtra DOSBox-X configuration. It is added after everything the settings produce, including [autoexec] lines. Use it for adjustments to a particular game that the settings do not cover.

Controls in each group

  • Add opens a file picker titled Add to and the group name. It starts in the ROM folder set under Config, Paths. It filters to the group's file types, and you can switch it to All files. You can select several files at once.
  • Remove takes the selected row out of the list. It does not delete the file on disk.
  • Up and Down arrows appear in the groups that take more than one file, which are Floppy disks and CD-ROMs. They move the selected row. The order is kept in the project.
  • Drag and drop works on each list. A file you drop lands in the group you drop it on. Folders are ignored.

Rules

  • At least one file is needed across Floppy disks, CD-ROMs, Hard disk and Configuration file. Next will not continue until there is one.
  • Each group's title shows how many files it takes and the file types it expects. A file with another extension is still added, and a message at the bottom tells you it is not what the group expects.
  • Adding a file with the same name as one already in the group does nothing.
  • A .cue file (a small text file that lists a disc's track files) counts as one row and shows how many track files it brings. All its track files must sit in the same folder as the .cue file, or the wizard refuses it and names the missing file.

Starting from a dropped file

If you drag a file onto the main Chimera window, the wizard opens with the core that claims the file's extension already chosen. The file goes into the first group that lists that extension. DOSBox-X claims .conf, .fdi, .hdd, .ima, .img, .xdf.

Page 3 Set up the machine

This page asks for the emulation settings. Every setting here shapes the emulated machine, and the project records each one at the value you leave it on. A recording made with a project only plays back correctly with the same settings.

Preset

A preset is a ready-made group of setting values. Pick one in the Preset box and press Apply. Apply writes the preset's values into the grid below, and you can change any of them afterwards. The project stores the values and not the preset name. A message at the bottom says how many settings were applied.

Settings

The grid lists the settings alphabetically. Click a row to read its description in the pane under the grid. A value that differs from the default is shown in bold. Right-click a row and choose Reset to put the default back. True or False settings and settings with a fixed set of choices are picked from a list. Number and text settings are typed in. The System and Renderer are not in the grid because Page 1 already asked for them. DOSBox-X has 33 settings in the grid. All of them are always shown.

SettingAllowed valuesDefaultWhat it does
Boot Fromnone, a, cnoneStarts the machine from a drive instead of showing the DOS prompt. 'a' starts from a bootable floppy image and 'c' starts an operating system installed on the hard disk. 'none' keeps DOSBox-X's built-in DOS prompt. This setting was added for Chimera, and BizHawk movies use 'none'.
CD-ROM Insertion Delay (ms)0 to 600000How long the CD-ROM drive reports that it is empty after a disc is changed, in milliseconds. This stands for the time a person takes to change the disc. 0 uses the drive's default, which is no delay. Windows 95 and later need about 4000 to notice a new disc automatically.
CPU Corenormal, full, simplenormalWhich of DOSBox-X's interpreters runs the x86 code. 'normal' is the accurate one and is used by every machine preset here. 'simple' is faster and only for real-mode software. 'full' is the slowest and the most exact. DOSBox-X's recompiling ('dynamic') cores are not included, because they cannot be made to give the same result on every computer, and a movie needs that.
CPU Cycles1 to 1000000022000How many processor cycles the machine executes in each emulated millisecond. DOSBox measures processor speed this way and not in MHz. Rough values are 315 for a 4.77 MHz 8086, 2300 for a 10 MHz 286, 22000 for a 50 MHz 486 and 200000 for a late Pentium. Lower it for a game that runs too fast and raise it for one that stutters. It is always a fixed number. DOSBox-X's 'auto' and 'max' follow the speed of your computer, which a movie could not reproduce.

18 choicesauto, 8086, 8086_prefetch, 80186, 80186_prefetch, 286, 286_prefetch, 386, 386_prefetch, 486old, 486old_prefetch, 486, 486_prefetch, pentium, pentium_mmx, ppro_slow, pentium_ii, pentium_iii

'auto' lets DOSBox-X choose the type that fits the rest of the machine. The choices ending in '_prefetch' also imitate the real chip's instruction queue, which a few programs that depend on exact timing need.
Enable Joystick 1True or FalseTrueWhether a joystick is plugged into game port 1.
Enable Joystick 2True or FalseTrueWhether a joystick is plugged into game port 2.

Fake INT 13h Disk I/OTrue or FalseFalseMakes the emulated hard disk and floppy controllers respond to BIOS disk calls the way real hardware does. Initial Driveauto, a, c, dautoThe drive the DOS prompt starts on. 'auto' uses the first drive the project put a disk in, looking in the order A (a floppy), D (a CD) and C (the hard disk). If a drive is named here and has no disk, the same order is used. Z, DOSBox-X's own drive of built-in commands, is never offered, because a project always has a disk or gets a formatted one. The one exception is a project made only of a configuration file, which stays on Z. The starting drive changes what the prompt shows, so a movie recorded before this setting existed plays back on a machine whose prompt looks different. Set it to match if that matters. It is ignored when Boot From starts an operating system, because the prompt is then never shown.
MIDI Devicenone, mt32_old, mt32_new, cm32lnoneWhat is connected to the machine's MIDI port (MPU-401). 'none' leaves the port unconnected, as every one of these machines was sold. 'mt32_old' is a first-generation Roland MT-32 (control ROM version 1.07), whose peculiarities the earliest Sierra games rely on. 'mt32_new' is the second generation (version 2.04). 'cm32l' is a Roland CM-32L or LAPC-I (version 1.02), an MT-32 with the extra sound effects that later games use. Each needs its control ROM and PCM ROM, copied from a unit you own.
Mount Formatted Hard Disk Drivenone, 21mb, 41mb, 241mb, 504mb, 2014mbnoneWhether an empty, formatted, writable hard disk is put in as drive C. The disk is kept completely in memory, so make sure your computer has enough memory. Its contents are this core's save data (Emulator > Export Save Data). This setting is ignored when a hard disk image is given.
Mouse Relative Sensitivityany decimal number0.5Every relative mouse movement is multiplied by this number before the machine receives it. It applies to Mouse Speed X/Y and to the movement that Mouse Set Position causes. It changes how far the mouse has to travel, not where the pointer ends - a position set with Mouse Set Position still lands where it says. The value used to be 3.0 (the value in the BizHawk version of this core), which moved the DOS pointer about three times as far as asked.
PC Speakerdisabled, enabledenabledWhether the machine's built-in speaker is connected. Every machine here had one, and DOS games from before sound cards play their music on it. Turning it off silences that music and changes nothing else.
RAM Size (KB)0 to 2621440Kilobytes of memory ADDED to RAM Size (MB), for machines with less than a megabyte - 256 for a 1981 PC and 640 for an XT or a PS/2 25. Leave it at 0 for anything from 1986 on, where RAM Size (MB) is enough.
RAM Size (MB)0 to 25632The memory size in whole megabytes. Computers of the time had very little - 0 for a PC from before 1987 (RAM Size (KB) then gives the real amount), 1 to 8 for the 286 and 386 years, and 32 to 128 for a late Pentium. More memory is not always better, because some DOS games refuse to start when they find more than they expect.
Reported DOS Versionauto, 3.3, 5.0, 6.22, 7.0, 7.1autoThe version number DOSBox-X's built-in DOS reports to programs. 'auto' lets it choose (currently 5.0, the safest for DOS games). 6.22 is the last real MS-DOS. 7.0 and 7.1 are the DOS versions inside Windows 95 and 98, which some installers and programs that use long file names look for. Sound Blaster IRQ-1 to 15-1The interrupt line (IRQ) the Sound Blaster uses. -1 uses the card model's factory default (7 for the early cards, 5 for a Sound Blaster 16), which is what a game's setup program expects.

Choose the card the game was written for. A game from 1990 does not use the extra features of an sb16, and a game from 1995 may refuse an sb1.
Use Chimera Mouse DriverTrue or FalseTrueLets Mouse Position (with Mouse Set Position held) place the pointer exactly in Windows 3.1, 95 and 98. Without it the pointer is pushed through Windows' own mouse acceleration and does not land exactly. With this on, drive B holds Chimera's mouse drivers and their installer. Before anything else starts, the installer puts the right driver into the Windows found on drive C (CHIMABS.EXE, started from WIN.INI, for Windows 95 and 98, and VBADOS' VBMOUSE.DRV for Windows 3.1). It writes to C only when the driver is not there yet, and it leaves a disk without Windows alone. Turning this off removes drive B but does not remove an installed driver. It is not available on PC-98 machines, which these drivers are not made for. B\README.TXT says more, and B\INSTALL installs the driver by hand.

Use PC-98 Font ROMTrue or FalseFalseDraws PC-98 text with a real NEC character ROM (FONT.ROM) instead of the built-in free font. It only has an effect when Video Card Type is one of the pc98 choices.
Use PC-98 Rhythm SamplesTrue or FalseFalseGives the sound chip of the PC-9801-86 board (YM2608) its six built-in drum samples (2608_bd, sd, top, hh, tom and rim .wav). Without them FM music plays with no drums. It only has an effect when Video Card Type is one of the pc98 choices.
Use PC-98 Sound BIOSTrue or FalseFalseAdds the BIOS of the PC-9801-26K/86 sound board (SOUND.ROM) to the machine, at address CC000h. The board's FM sound works without it. Games that call the sound BIOS need it. It only has an effect when Video Card Type is one of the pc98 choices.
Use Real Video BIOSTrue or FalseFalseUses a real video BIOS copied from the card chosen in Video Card Type, instead of the one DOSBox-X makes itself. It is for software that examines the card's BIOS.
VESA Mode List Height Limit0 to 40961024The same limit for the height of VESA video modes. 1024 is DOSBox-X's own limit, and 0 lists every mode.
VESA Mode List Width Limit0 to 40961280Hides VESA video modes wider than this many pixels from the list a program gets. Some DOS programs cannot handle a long list or a very large mode. 1280 is DOSBox-X's own limit. 0 lists every mode the card has, which a Windows 95 or 98 display driver needs.

Page 4 Provide firmware

This page asks where to find the firmware files your choices need. It only appears when at least one setting calls for a file. With some settings it is skipped, and the page before it ends with Create instead of Next. The list changes when you go back and change a setting.

The list

Each row shows the firmware name, the file name the core expects, its SHA1 and its status. The status reads "found" followed by a file name, "your own" followed by a file name, "not found", or "optional - core default used". A green row has a file and a red row does not. Hover over a row to read what the file is for.

Chimera looks in the Firmware folder first. That folder is set under Config, Paths and is called Firmware beside Chimera.exe by default. It also looks at files you chose for this core before. A file it finds is matched by its SHA1, so its name does not matter.

Buttons

  • Select File picks a file for the selected row. Double-clicking a row does the same. It works even when a file was already found. If the row shows a SHA1, the file must match it, or the wizard refuses the file and shows the SHA1 it found. A row that shows "(your own file)" has no fixed SHA1, so any file is accepted and its SHA1 is recorded.
  • Clear removes the file chosen for the selected row.
  • Scan Folder searches a folder you pick and fills every row it can. The folder picker has an Include sub-folders box, ticked by default. Turn it off for a very large folder. A row with a SHA1 takes only the exact file. A row with no SHA1 takes the file with the expected name. A message at the bottom says how many files were scanned and how many rows were filled.

Create stays greyed out until every row that is not optional has a file.

Create the project

On the last page the Next button reads Create. Chimera then reads every file you added, which can take a while for large files, and checks them against the core's rules. If a file is refused, the wizard goes back to Page 2 and says why. If all is well, the wizard closes and the project opens in TAStudio at the first frame, which is the first picture the game draws.

Some cores add a page that compiles the game's code before the project is made. DOSBox-X does not, so you will not see it.

A project's settings cannot be edited once it exists, because a changed setting is a different machine. To change one, choose New Chimera Project again. The wizard opens filled in with your last answers, so you change that one setting and go through the pages to Create again.
