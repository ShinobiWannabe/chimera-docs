MAME

Quickstart

System Arcade

Quickstart

  1. Put the MAME core file (it ends in .chimeraCore) in the Cores folder next to Chimera.exe.
  2. Open the File menu and choose New Chimera Project.
  3. Page 1. Choose MAME in the Core list, then press Next.
  4. Page 2. Press Add under Rom set and pick your game files. Press Next.
  5. Page 3. Change settings if you want to. The defaults work for most games. Press Next, or Create if that is what the button says.
  6. Chimera opens the new project in TAStudio (its input editor) at the first frame.

You can also drag a game file onto the Chimera window. The wizard then opens with the core and the file already chosen.

Before you begin

  • A core is the package that holds an emulator. This page uses the MAME core, which runs Arcade. You get it from the Releases page of the chimera-core-mame repository on GitHub. In Chimera, the File menu entry Core Manager lists the cores you have installed.
  • A project is what Chimera creates for one game. It records the names and SHA1 values of your files, your settings and your recorded inputs. A SHA1 is a fingerprint of a file's contents. A project never records where your files are on disk.
  • Firmware means system files copied from real hardware or from a game, such as a BIOS (the built-in startup program of a console or computer). Chimera does not include any.
  • Nothing is saved to disk when you press Create. The project stays in memory until you choose Save Project, which asks where to put it.
  • A frame is one picture the game draws. A game draws many of them each second.

Buttons on every page

ButtonWhat it does
BackReturns to the page before. It is greyed out on Page 1. Pages that do not apply are skipped. Your answers are kept.
NextGoes to the next page. On the last page it is called Create. If something is missing, a red message at the bottom left says what.
CancelCloses the wizard and creates nothing.

Page 1 Choose the core

The first page asks you to pick a core, either an emulator or a game. Everything on the later pages depends on this choice.

OptionWhat it does
KindEmulator or Game. It decides which cores the Core list shows. MAME is an emulator. The wizard opens on the kind you used last, when you have cores of that kind installed.
CoreLists the installed cores of that kind. Each line shows the core name, its version date and the systems it runs. Choose the MAME line. If you have two builds of one core installed, the line also shows the first eight characters of the package's fingerprint in square brackets.
SystemNames the machine to emulate. MAME has one, Arcade, so the box is greyed out.
RendererChooses how the picture is drawn, for cores that offer a choice. MAME draws one way, so the box is greyed out and shows Software (Native).

A link at the bottom takes you to the Chimera issue page, for reporting problems and asking for features. If no core is installed, Next shows a message asking you to pick one.

Page 2 Add your files

This page asks for the game files and other data. The core decides what appears here. MAME shows 3 groups of files. Hover over a group to see the core's own help text.

GroupHow manyFile typesWhat it is for
Rom setExactly one.zip, .7zThe game's ROM set, with the file name MAME uses (for example ssf2t.zip). The name is how the core knows which game it is. The other sets the game reads from - its board's BIOS set (neogeo.zip), its parent's set if it is a clone, the sets of the devices it uses (qsound_hle.zip) - are asked for on the Firmware page, where Chimera remembers them for the next game. The settings page names every file that is missing.
Disc images0 to 8.chdThe CHD images of a game that has a hard disk, a CD or a laserdisc, with the file names MAME uses (for example 420uaa04.chd). The settings page names an image that is missing.
Save data0 to 32.nvWhat the machine keeps when the power is off, in the files Export Save Data wrote - its settings, its high scores, its EEPROM. Each file is put back into the device it came from before the first frame. With none, the machine starts as it left the factory.

Controls in each group

  • Add opens a file picker titled Add to and the group name. It starts in the ROM folder set under Config, Paths. It filters to the group's file types, and you can switch it to All files. You can select several files at once.
  • Remove takes the selected row out of the list. It does not delete the file on disk.
  • Up and Down arrows appear in the groups that take more than one file, which are Disc images and Save data. They move the selected row. The order is kept in the project.
  • Drag and drop works on each list. A file you drop lands in the group you drop it on. Folders are ignored.

Rules

  • Groups whose How many is Exactly one or At least one need a file. These are Rom set. Next will not continue until each has a file.
  • Each group's title shows how many files it takes and the file types it expects. A file with another extension is still added, and a message at the bottom tells you it is not what the group expects.
  • Adding a file with the same name as one already in the group does nothing.

Page 3 Set up the machine

This page asks for the emulation settings. Every setting here shapes the emulated machine, and the project records each one at the value you leave it on. A recording made with a project only plays back correctly with the same settings.

Settings

The grid lists the settings alphabetically. Click a row to read its description in the pane under the grid. A value that differs from the default is shown in bold. Right-click a row and choose Reset to put the default back. True or False settings and settings with a fixed set of choices are picked from a list. Number and text settings are typed in. The System and Renderer are not in the grid because Page 1 already asked for them. MAME has 0 settings in the grid. All of them are always shown.

When you arrive on this page, Chimera asks the core to look up your game. If the core knows it, Chimera applies settings that suit the game and shows a note above the grid with where they came from, or that the game is not known. The note also lists the settings it changed. The core can also add settings that exist only for your game.

Create the project

On the last page the Next button reads Create. Chimera then reads every file you added, which can take a while for large files, and checks them against the core's rules. If a file is refused, the wizard goes back to Page 2 and says why. If all is well, the wizard closes and the project opens in TAStudio at the first frame, which is the first picture the game draws.

Some cores add a page that compiles the game's code before the project is made. MAME does not, so you will not see it.

A project's settings cannot be edited once it exists, because a changed setting is a different machine. To change one, choose New Chimera Project again. The wizard opens filled in with your last answers, so you change that one setting and go through the pages to Create again.
