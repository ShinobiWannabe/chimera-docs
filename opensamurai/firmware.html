About this data

22 firmware entries, 22 rows. 'Also required only when' holds the part of the rule that still depends on another setting or on a file slot. Label is the firmware's own label and is empty when the config gives none. An empty rule means the file is always needed. Entries marked [Optional] can be skipped. A size of 0 means any size is fine.
