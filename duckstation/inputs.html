About this data

448 buttons and 160 axes, in the same order as the config. That order is the column order of a movie file. Order starts at 1 for each type. Mnemonic is the short letter for the button. Column Header is filled only when the config gives one. Buttons have no Min, Max or Neutral. Empty values are written as an empty string.
