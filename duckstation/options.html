DuckStation

Options

Settings the DuckStation core exposes in the New Project wizard. Click a column heading to sort. Click again to reverse. Settings that are identical on every machine are listed once.

Settings

32 of 32
Machineplaystation, namco_system11, konami_gqplaystationWhich machine this project is: the PlayStation, or one of the arcade boards built from PlayStation hardware. A PlayStation runs discs. An arcade board runs a MAME rom set, and each board runs only the sets made for it. Everything else follows from this choice: the files, the controls and the firmware.
BIOSv1.0-j, v1.1-j, v2.0-a, v2.0-e, v2.1-a, v2.1-e, v2.1-j, v2.2-a, v2.2-e, v2.2-j, v3.0-a, v3.0-e, v3.0-j, v4.0-j, v4.1-a, v4.1-e, v4.3-j, v4.4-e, v4.5-a, v4.5-ev4.1-aWhich of Sony's boot ROMs the console has. The boot ROM is the machine's operating system. It differs by region and by revision. For example 'v4.1-a' is version 4.1 for North America (the one in the SCPH-7001), a 'j' is for Japan and an 'e' is for Europe. A project records one of them, and Chimera asks for that file. A game runs on any BIOS that accepts its disc, but a movie plays back only on the one it was made with.
Console Regionauto, ntsc-u, ntsc-j, palautoWhich market the console was made for. It decides the video timing (NTSC 59.83 Hz or PAL 49.76 Hz) and which discs the drive accepts. 'auto' reads the disc and becomes the console that disc was made for, which is right for almost every game. With no disc it becomes the console its BIOS was made for.
Controller 1none, digital, dualshock, analogJoystick, negcon, negconRumble, guncon, justifier, mousedualshockWhat is plugged into port 1. 'dualshock' is the analog controller, in the mode it starts in when switched on. 'digital' is the original pad with no sticks. 'analogJoystick' is the flight controller with two sticks. 'negcon' is Namco's twisting pad for racing games, and 'negconRumble' is the later one with motors. 'guncon' and 'justifier' are the two light guns. They are not interchangeable, and a game works with one or the other. 'mouse' is the PlayStation Mouse. DuckStation's game database lists games that cannot work with a DualShock. Such a game gets the digital pad whatever is chosen here.
Controller 2none, digital, dualshock, analogJoystick, negcon, negconRumble, guncon, justifier, mousenoneWhat is plugged into port 2. By default nothing is, because a game can see any controller that is plugged in. 'dualshock' is the analog controller, in the mode it starts in when switched on. 'digital' is the original pad with no sticks. 'analogJoystick' is the flight controller with two sticks. 'negcon' is Namco's twisting pad for racing games, and 'negconRumble' is the later one with motors. 'guncon' and 'justifier' are the two light guns. They are not interchangeable, and a game works with one or the other. 'mouse' is the PlayStation Mouse. DuckStation's game database lists games that cannot work with a DualShock. Such a game gets the digital pad whatever is chosen here.
Multitapnone, port1, port2, bothnoneA multitap turns one controller port into four sockets, for games of up to five players (one multitap) or eight (two). 'port1' puts a multitap in port 1. Controller 1 is then its socket A, and Controllers 1B, 1C and 1D are its other three sockets. A game that was not written for the multitap may not see ANY controller through it, so leave it out unless the game asks for one. It is part of the machine, so a movie needs the same value.
Controller 1Bnone, digital, dualshock, analogJoystick, negcon, negconRumble, guncon, justifier, mousenoneWhat is plugged into socket B of the multitap in port 1 (P3 in a movie). It is empty unless that multitap is plugged in.
Controller 1Cnone, digital, dualshock, analogJoystick, negcon, negconRumble, guncon, justifier, mousenoneWhat is plugged into socket C of the multitap in port 1 (P4 in a movie). It is empty unless that multitap is plugged in.
Controller 1Dnone, digital, dualshock, analogJoystick, negcon, negconRumble, guncon, justifier, mousenoneWhat is plugged into socket D of the multitap in port 1 (P5 in a movie). It is empty unless that multitap is plugged in.
Controller 2Bnone, digital, dualshock, analogJoystick, negcon, negconRumble, guncon, justifier, mousenoneWhat is plugged into socket B of the multitap in port 2 (P6 in a movie). It is empty unless that multitap is plugged in.
Controller 2Cnone, digital, dualshock, analogJoystick, negcon, negconRumble, guncon, justifier, mousenoneWhat is plugged into socket C of the multitap in port 2 (P7 in a movie). It is empty unless that multitap is plugged in.
Controller 2Dnone, digital, dualshock, analogJoystick, negcon, negconRumble, guncon, justifier, mousenoneWhat is plugged into socket D of the multitap in port 2 (P8 in a movie). It is empty unless that multitap is plugged in.
Memory Card 1true, falsetruePuts a memory card in slot 1. The card is kept in the console's memory. It is part of every savestate and goes back in time together with the game that wrote to it. Nothing is written to your disk until you ask for it with Emulator > Export Save Data, which gives you memcard1.mcd. To start from a card you already have, put it in the project's Save Data under that name.
Memory Card 2true, falsefalsePuts a memory card in slot 2. It works the same way as Memory Card 1, and its file is memcard2.mcd.
Renderersoftware, opengl, opengl-hw, vulkan-hwsoftwareWhat draws the picture. 'software' is DuckStation's software renderer. It draws the console's own pixels and is the default. 'opengl' is DuckStation's hardware renderer, the one that Internal Resolution applies to, drawn by an OpenGL that is built into the core (Mesa's softpipe). No graphics card is used, so the picture is the same on every computer, and it is slow. 'opengl-hw' is that same renderer drawing on your computer's graphics card. This is fast, but it is NOT the same on every computer, because the card and its driver are outside the core. A movie made this way may not play back on another computer. If there is no graphics card, the softpipe draws instead. 'vulkan-hw' is the same renderer again, drawing on your graphics card with Vulkan instead of OpenGL. Like 'opengl-hw' it is fast and not the same on every computer. It has nothing to fall back on: on a computer with no Vulkan driver the game does not start, and says why. A game that reads its own picture back sees a different machine with each of these, so a project records the choice.
Internal Resolution1x, 2x, 3x, 4x, 5x, 6x, 7x, 8x1xHow many pixels the hardware renderer draws for each pixel of the console. At 2x a 320x240 game is drawn at 640x480, and at 8x at 2560x1920. Polygons become sharper, and 2D art stays the size it was made at. It does nothing with the software renderer. A game that reads its picture back gets it scaled down again, and that is not always exactly what it drew. So it is part of the machine, and a movie needs the same value.
True Colourtrue, falsefalseDraws in 24-bit colour instead of the console's 15-bit colour with dithering. Gradients lose their bands and their dither pattern. DuckStation turns this on by default. Here the console's own colour depth is the default, and this setting is the improvement. A game that reads its picture back gets it reduced to 15-bit again.
Scale Ditheringtrue, falsetrueMakes the dither pattern as fine as the picture, instead of the console's pattern enlarged. It applies when True Colour is off and Internal Resolution is above 1x. It has no effect at 1x.
Texture Filteringnearest, bilinear, bilinearBinAlpha, jinc2, jinc2BinAlpha, xbr, xbrBinAlphanearestHow the textures on 3D polygons are sampled. 'nearest' is what the console does: each texture pixel is a square. 'bilinear' blends neighbouring pixels. 'jinc2' and 'xbr' are sharper and slower. The 'BinAlpha' choices keep the edges of transparent areas hard, which avoids the halos that filtering otherwise draws around cut-out textures.
Sprite Texture Filteringnearest, bilinear, bilinearBinAlpha, jinc2, jinc2BinAlpha, xbr, xbrBinAlphanearestThe same choice for 2D sprites and backgrounds. These usually look better as the artist drew them.
Downsamplingdisabled, box, adaptivedisabledDraws at the Internal Resolution and then shrinks the picture that is handed to Chimera. 'box' averages everything back to the console's resolution. 'adaptive' keeps 3D sharp and smooths only 2D. 'disabled' hands over every pixel that was drawn.
PGXP Geometry Correctiontrue, falsefalseKeeps the corners of polygons at the precision the game calculated, instead of rounding them to whole pixels as the console did. This is what stops 3D models from wobbling. It does not change the picture only. The precise corners also decide which polygons are thrown away, and how long the console's graphics chip is busy depends on what it drew. So a game runs slightly differently with it, and a movie made with PGXP does not play back without it.
PGXP: Perspective Correct Texturestrue, falsetrueUses the depth that PGXP recovers to map textures in perspective. This straightens the warped textures that the console's simpler mapping gives large polygons.
PGXP: Perspective Correct Colourstrue, falsefalseThe same for shading. The difference is usually small, and it is wrong in a few games.
PGXP: Culling Correctiontrue, falsetrueAlso uses the precise corners to decide which polygons face away. This closes the hairline gaps that precise corners otherwise open.
PGXP: Depth Buffertrue, falsefalseGives polygons a depth test, which the console did not have, to stop them poking through each other. It breaks games that draw in an order of their own. The depth of a frame is not kept in a savestate. After a load it starts empty, as it does on every frame where the game clears it.
PGXP: CPU Modetrue, falsefalseTracks precise values through every processor instruction, and not only through the geometry chip. A few games need it. It is much slower.
Widescreen Hackoff, 16:9, 19:9, 20:9offDuckStation's widescreen hack. The game's 3D view is widened to suit a screen of this shape, by changing what its geometry processor calculates. The picture is still the console's own, squeezed. Set Config > Display > Aspect Ratio to the same shape to see it as intended. The 2D parts of a game (menus, status displays, sprites) are not widened and look stretched. It changes the MACHINE and not only the picture: different geometry is drawn, and that takes the video chip a different time. So a movie made with it needs it. DuckStation's game database lists games that break with it, and for those it is turned off.
Cropoverscan, none, bordersoverscanHow much of the console's picture is handed to Chimera. 'overscan' cuts off what the edge of a television hid. 'none' keeps the whole picture, black edges included. 'borders' cuts to the area the game placed its picture in. It changes the picture only.
Interlaced Modesweave, progressiveweaveWhat happens in the console's interlaced video modes (480 lines, used by most menus and by many games). 'weave' is what the console does. On each frame it draws and shows one field, which is every other line, and the frame handed to Chimera is that field combined with the previous one, as a television showed it. 'progressive' is DuckStation's own default and an improvement: every line is drawn on every frame. The picture is steadier, but it is a different machine, because video memory no longer holds what a PlayStation would have put there.
Skip the Console Boottrue, falsefalseStarts the game without the console's own logos. The ROM is patched to jump past them, so the machine reaches the game in a different state from one that started in full. A movie made one way does not play back the other way.
Log the Machinetrue, falsefalseWrites DuckStation's own log, and the messages it would have shown on screen, to the core's output. It does not change the machine.

About this data

32 settings, 66 rows. There is one row for each machine and each option. A setting for several machines is repeated for each machine. A setting with no rule is listed under every machine as 'Always shown'. Origin says where the setting came from. The last field holds a rule that depends on another setting or slot, so a setting can still be hidden even when its machine matches.
