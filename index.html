Home

Reference documentation for Chimera, the TAStudio input editor and the Chimera emulator cores. Start with the Chimera Quickstart, or pick a core to see its quickstart, systems, firmware, options, inputs and notes.

Chimera

The Chimera frontend is the program window that loads cores and runs your projects.

QuickstartChimeraLoad a system core or a game-specific core and start a project.Menu OptionsChimeraA short description of each menu and each menu item in the Chimera window.Core ManagerChimeraSee the cores installed in the Cores folder, check their version and licence, and remove old ones.Cache ManagerChimeraSee what Chimera keeps on disk that it can rebuild, lock the parts you want to keep, and clear the rest.Reproducible Media MakerChimeraPack a folder into one disc, zip or floppy file that has the same SHA1 for everyone.EncodingChimeraWrite a video file of a stretch of your movie between two markers.ControllersChimeraBind keys and pads to the buttons of the emulated controllers.HotkeysChimeraBind keys to Chimera commands such as frame advance, speed changes and TAStudio actions.CustomizeChimeraGeneral and advanced options for how the Chimera window behaves.RAM WatchChimeraKeep a list of memory values on screen, change them, or freeze them.RAM SearchChimeraFind the memory address of a value by comparing how memory changes while the game runs.Lua ConsoleChimeraRun Lua scripts that read memory, press buttons and draw on the screen.Hex EditorChimeraView and edit the machine's memory as hexadecimal numbers.Macro ToolChimeraCopy a stretch of input from the movie and place it somewhere else.MCP ServerChimeraLet an AI agent look at your open project, and edit it if you allow it, through a local MCP server.Report an IssueChimeraPrepare a bug report with the build details and files that help the developers.

TAStudio

TAStudio is the window where you edit a movie one frame at a time.

QuickstartTAStudioOpen TAStudio by loading a system core or a game-specific core.Menu OptionsTAStudioA short description of each menu and each item in the TAStudio window.Piano RollTAStudioThe table of frames and buttons where you edit your input.PlaybackTAStudioButtons and options for moving through the movie and for recording.GreenzoneTAStudioSaved game states that make jumping to earlier frames fast.MarkersTAStudioNamed points in the movie that you can jump to, select between and encode between.BranchesTAStudioSaved copies of your work that you can return to while you try something else.Split Input RollsTAStudioUse the column header menu to autohold buttons, hide and show columns, and split the piano roll into several rolls.

Cores

Emulator cores run a whole system. Game cores run one game.
