DSDA-Doom

Options

Settings the DSDA-Doom core exposes in the New Project wizard. Click a column heading to sort. Click again to reverse. Settings that are identical on every machine are listed once.

Settings

Gamedoom2, doom, tnt, plutonia, heretic, hexen, chex, freedoom1, freedoom2doom2Which game the machine is (Chimera's System). It is the game the IWAD belongs to. It is not shown on the settings page.
Compatibility Level0 - Doom v1.2, 1 - Doom v1.666, 2 - Doom & Doom 2 v1.9, 3 - Ultimate Doom & Doom95, 4 - Final Doom, 5 - DOSDoom, 6 - TASDoom, 7 - Boom's Vanilla Compatibility Mode, 8 - Boom v2.01, 9 - Boom v2.02, 10 - LxDoom, 11 - MBF, 12 - PrBoom v2.03beta, 13 - PrBoom v2.1.0, 14 - PrBoom v2.1.1 - 2.2.6, 15 - PrBoom v2.3.x, 16 - PrBoom v2.4.0, 17 - PrBoom Latest, 21 - MBF212 - Doom & Doom 2 v1.9The version of Doom, or of one of its ports, whose behaviour this movie follows. The highest level that is compatible with the original game is 'Final Doom'. Newer WADs may need a higher level. DSDA-Doom used alone defaults to MBF21, which supports the features of all lower levels but is the furthest from the original game.
Skill Level1 - I'm too young to die, 2 - Hey, not too rough, 3 - Hurt me plenty, 4 - Ultra-Violence, 5 - Nightmare!4 - Ultra-ViolenceThe difficulty. The original game defaults to 'Hurt me plenty', but 'Ultra-Violence' is the usual standard today.
Multiplayer ModeSingle Player / Cooperative, Deathmatch, Alternate Deathmatch (v2.0)Single Player / CooperativeWhich multiplayer mode the game is played in.
Initial Episode0 to 91The episode the game starts in. It is ignored for IWADs without episodes (for example DOOM2) and for Shareware.
Initial Map1 to 991The map the game starts in.
Fast Monsterstrue, falsefalseMakes monsters move and attack much faster. It is always on at the Nightmare! difficulty.
Monsters Respawntrue, falsefalseMakes monsters come back to life shortly after dying. It is always on at the Nightmare! difficulty.
No Monsterstrue, falsefalseRemoves all monsters from the level.
Pistol Starttrue, falsefalseStarts every level from nothing, with no weapons or items kept from earlier levels. Health is also reset to 100%.
Coop Mode Spawnstrue, falsefalsePlays a single-player game with the monsters and items that the cooperative mode places.
Chain Episodestrue, falsefalseFinishing one episode leads to the next without a break. The original game does not have this.
Always Runtrue, falsetrueWhether the player always runs, with the slower walking speed not available. This reproduces a bug in the original Doom: setting the joystick run button to an invalid high number makes the game treat it as always pressed.
Render Wipescreentrue, falsetrueTurns on the screen melt, the effect shown when Doom changes scene, for example when a level starts or ends. The original game cannot turn it off. Its frames are lag frames, in which the game waits.
Turning Resolution16 bits (longtics), 8 bits (shorttics)16 bits (longtics)'Shorttics' is the reduced turning precision normally used for demos. 'Longtics' is the normal turning precision outside demo recording. Newer demo formats support both.
Horizontal Mouse Sensitivity0 to 10010How fast the player turns when the mouse is used.
Vertical Mouse Sensitivity0 to 1001How fast the player runs when the mouse is used.
Turning During Strafe50Ignore, AllowAllowThe "Strafe" key is needed to turn a turning movement into the fastest sideways movement (strafe50). Without it the largest sideways value is 40. So with a keyboard and a mouse it is impossible to turn during strafe50. If strafe50 together with turning appears in a demo, the game accepts it, which makes it possible only in a tool-assisted run. This setting can turn it off for the most authentic behaviour.
Prevent Level Exittrue, falsefalseLevel exits have no effect. This is useful for debugging, optimising and scripted play. The original game does not have this.
Prevent Game Endtrue, falsefalseThe triggers that end the game have no effect. This is useful for debugging, optimising and scripted play. The original game does not have this.
Turbo-1 to 255-1Changes the player's running and sideways speed (0 to 255). -1 means it is off.
Initial RNG Seed0 to 21474836471993The starting value (seed) of the game's random number generator. It is used only for compatibility level 7 (Boom) and above. The default value is 1993.
Player 1 Presenttrue, falsetrueWhether player 1 is present.
Player 2 Presenttrue, falsefalseWhether player 2 is present.
Player 3 Presenttrue, falsefalseWhether player 3 is present.
Player 4 Presenttrue, falsefalseWhether player 4 is present.
Internal Resolution Scale Factor1 to 121The number the internal resolution is multiplied by (1 to 12). The picture looks sharper but is less faithful to the original. The original game's resolution is 320x200, stretched to a 4:3 shape on a CRT monitor. The core's picture is at most 3840x2400, so the widescreen shapes go up to 5.
Internal Aspect RatioNative, 16:9, 16:10, 4:3NativeThe shape of the picture the game draws. 'Native' is a multiple of 320x200, and Chimera stretches it to 4:3, much like the original game. The other choices draw a picture that already has the right shape. That is useful for viewing the Automap at higher resolutions, because it avoids the distorted pixels that stretching afterwards causes.
Sfx Volume0 to 158The volume of the sound effects (0 to 15).
Music Volume0 to 158The volume of the music (0 to 15).
Gamma Correction Level0 to 40Makes the picture brighter (0 to 4). The original game's default is "OFF" (0). The Change Gamma button steps through the values.
Show Messagestrue, falsetrueShows messages about the items you pick up. The original game's default is "ON".
Report Revealed Secretstrue, falsefalseShows a message on screen when a secret is found. The original game does not have this.
HUD ModeVanilla, DSDA, NoneVanillaWhich heads-up display (HUD) is shown.
Extended HUDtrue, falsefalseShows DSDA-Doom's own information above the original heads-up display. The original game does not have this.
Display Coordinatestrue, falsefalseShows the player's position, angle, speed and distance travelled per frame. The colour shows the kind of movement: green for SR40, blue for SR50, red for turbo or wallrun. The original game has this through the IDMYPOS cheat code, but it shows only the angle, X and Y.
Display Commandstrue, falsefalseShows the recent inputs on the screen. The last 10 are kept, and empty inputs are left out. The original game does not have this.
Automap Totalstrue, falsefalseShows the counts of kills, items and secrets on the Automap. The original game does not have this.
Automap Timetrue, falsefalseShows the elapsed time on the Automap. The original game does not have this.
Automap Coordinatestrue, falsefalseShows the coordinates within the level on the Automap. The original game does not have this.
Automap OverlayDisabled, Enabled, DarkDisabledShows the Automap on top of the game view. The original game does not have this.
Automap DetailsNormal, Linedefs, Linedefs and thingsNormalShows all lines (linedefs) and things on the Automap. The original game has this through the IDDT cheat code.
Map Trailtrue, falsefalseShows the player's earlier positions as a trail when Automap Details is on. The original game does not have this.
Map Trail Size1 to 350105How many earlier positions are shown as a trail on the Automap (1 to 350).
Full Visiontrue, falsefalseRemoves all darkness. The original game has this through the IDBEHOLDL cheat code.
Player Point of View1 to 41Which player's point of view the picture is drawn from (1 to 4). If that player is not present, the first player who is present is used.
Solo Nettrue, falsefalsePlays a single player as a network game (DSDA-Doom's -solo-net option), which the footer of a demo may ask for. A game with more than one player is a network game anyway.
Boom/MBF OptionsAny textThe game options stored in the header of a demo made for Boom or a later port, written as hexadecimal. They are the 64 bytes of Boom, MBF and PrBoom, or the 21 bytes of MBF21 followed by its compatibility flags. They cover monster memory, friction, pushers, bobbing, demo insurance, infighting, helper dogs and their distance, the monsters' behaviour and the compatibility flags. When this is empty, the defaults of the compatibility level and a PWAD's OPTIONS lump are used, as DSDA-Doom records them. The monster flags and the seed are taken from the settings, not from this value.
Extended CommandsOff, On, On, with casual featuresOffDSDA-Doom's extended commands, which its own DSDA demo format holds: jumping and free look, and, with the casual features, god mode and walking through walls. It is off for every other demo format.
Emulate PrBoom+ VersionAny textPlays the way an older PrBoom+ did (DSDA-Doom's -emulate option, with a version such as 2.5.0.8), which the footer of a demo may ask for. When this is empty, the game plays as DSDA-Doom does.
Spechit Overrun Base Address0 to 21474836470The memory address that the emulation of the spechit overflow assumes (DSDA-Doom's -spechit option), which the footer of a demo may give. 0 means the address in doom2.exe (0x01C09C98).
Emulate Spechit Overflowtrue, falsetrueReproduces the original game's spechit overflow bug (DSDA-Doom's overrun_spechit_emulate option, which is on by default).
Emulate Reject Overflowtrue, falsetrueReproduces the original game's REJECT overflow bug (the overrun_reject_emulate option, which is on by default).
Emulate Intercepts Overflowtrue, falsetrueReproduces the original game's intercepts overflow bug (the overrun_intercept_emulate option, which is on by default).
Emulate Playeringame Overflowtrue, falsetrueReproduces the original game's playeringame overflow bug (the overrun_playeringame_emulate option, which is on by default).
Emulate Donut Overflowtrue, falsefalseReproduces the original game's donut overflow bug (the overrun_donut_emulate option, which is off by default).
Emulate Missed Backside Overflowtrue, falsefalseReproduces the original game's missed backside overflow bug (the overrun_missedbackside_emulate option, which is off by default).

About this data

61 settings, 497 rows. There is one row for each machine and each option. A setting for several machines is repeated for each machine. A setting with no rule is listed under every machine as 'Always shown'. Origin says where the setting came from.
