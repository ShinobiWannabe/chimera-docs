xemu

Options

Settings the xemu core exposes in the New Project wizard. Click a column heading to sort. Click again to reverse.

Settings

9 of 9
CPU speed500, 1000, 250, 125500How many million instructions per second the Xbox's processor is assumed to execute. This decides how much work fits in a frame, so it is part of the machine and not just a speed control. The console's processor is a 733 MHz Pentium III. In practice it executes about 440 to 590 million instructions a second, and it cannot reach 1000. The setting can only move in power-of-two steps, so 500 and 1000 are the only values near the real figure. 500 is closer and also cheaper to emulate, so it is the default. Lower values make the console slower than the real one, and games then drop frames where the real console did not. They are offered for when emulation speed matters more. A movie recorded at one value does not play back at another.
Controller in Port 1none, dukedukeWhat is plugged into controller port 1. 'duke' is the original Xbox controller, the one this core emulates. With the port empty, games find nothing connected there, as on a real console. The port's buttons and sticks are then also removed from the input columns and from the movie.
Controller in Port 2none, dukenoneWhat is plugged into controller port 2. 'duke' is the original Xbox controller, the one this core emulates. With the port empty, games find nothing connected there, as on a real console. The port's buttons and sticks are then also removed from the input columns and from the movie.
Controller in Port 3none, dukenoneWhat is plugged into controller port 3. 'duke' is the original Xbox controller, the one this core emulates. With the port empty, games find nothing connected there, as on a real console. The port's buttons and sticks are then also removed from the input columns and from the movie.
Controller in Port 4none, dukenoneWhat is plugged into controller port 4. 'duke' is the original Xbox controller, the one this core emulates. With the port empty, games find nothing connected there, as on a real console. The port's buttons and sticks are then also removed from the input columns and from the movie.
Rendereropengl-hwopengl-hwWhich renderer draws the picture. There is only one, xemu's OpenGL renderer, which draws on your computer's graphics card outside the sandbox. On an Xbox, what the graphics chip draws goes back into the console's own memory. A different graphics driver can therefore give a slightly different machine, and a movie recorded here plays back only on the same driver. A renderer that draws nothing exists for the core's own tests. It is not for playing and is not offered.
Internal Resolution1x, 2x, 3x1xHow large the graphics card draws everything (xemu's surface scale). The Xbox usually draws at 640x480. '2x' and '3x' draw the same frame at 1280x960 and 1920x1440, so edges are smoother and a recording has real detail. It costs graphics time and makes the picture larger. THIS SETTING AFFECTS SYNC. Everything the graphics chip draws is written into the console's memory, and a larger picture is reduced on the way by keeping only every second or third pixel. That is not what a 1x picture would have put there. Measured on Prince of Persia over 600 frames, 2x differs from 1x in 1.5 million bytes of memory, while two 1x runs are identical. A game that reads its own picture reads different bytes. So this is part of the machine. The project and the movie record it, and a movie recorded at one value needs the same value to play back. Choose it when the project is created and do not change it afterwards.
Halt the kernel's idle looptrue, falsetrueThe Xbox system software never stops the processor. When a game has nothing to do, it runs a small waiting loop until the next interrupt, and emulating that loop is expensive (96 percent of a frame in Prince of Persia's menus). With this on, the loop is replaced by an instruction that makes the processor sleep until the next interrupt. The console's clock reads the same and the game runs the same, and idle time costs almost nothing. It is part of the machine, so a movie recorded with it on plays back only with it on.
128MB RAM (debug console)true, falsefalseA retail Xbox has 64 MB of memory. Development consoles had 128 MB, and a few homebrew programs use it. The amount of memory is part of the machine, so two projects that differ here cannot share movies.

About this data

9 settings, 9 rows. There is one row for each machine and each option. A setting for several machines is repeated for each machine. A setting with no rule is listed under every machine as 'Always shown'. Origin says where the setting came from.
