Vita3K

Full Guide

System PlayStation Vita

Before you begin

  • A core is the package that holds an emulator. This page uses the Vita3K core, which runs PlayStation Vita. You get it from the Releases page of the chimera-core-vita3k repository on GitHub. In Chimera, the File menu entry Core Manager lists the cores you have installed.
  • A project is what Chimera creates for one game. It records the names and SHA1 values of your files, your settings and your recorded inputs. A SHA1 is a fingerprint of a file's contents. A project never records where your files are on disk.
  • Firmware means system files copied from real hardware or from a game, such as a BIOS (the built-in startup program of a console or computer). Chimera does not include any.
  • Nothing is saved to disk when you press Create. The project stays in memory until you choose Save Project, which asks where to put it.
  • A movie is a recording of the inputs you press. It plays back the same way each time.
  • A savestate is a copy of the whole machine at one moment. You can return to it later.
  • A frame is one picture the game draws. A game draws many of them each second.

Buttons on every page

ButtonWhat it does
BackReturns to the page before. It is greyed out on Page 1. Pages that do not apply are skipped. Your answers are kept.
NextGoes to the next page. On the last page it is called Create. If something is missing, a red message at the bottom left says what.
CancelCloses the wizard and creates nothing.

Page 1 Choose the core

The first page asks you to pick a core, either an emulator or a game. Everything on the later pages depends on this choice.

OptionWhat it does
KindEmulator or Game. It decides which cores the Core list shows. Vita3K is an emulator. The wizard opens on the kind you used last, when you have cores of that kind installed.
CoreLists the installed cores of that kind. Each line shows the core name, its version date and the systems it runs. Choose the Vita3K line. If you have two builds of one core installed, the line also shows the first eight characters of the package's fingerprint in square brackets.
SystemNames the machine to emulate. Vita3K has one, PlayStation Vita, so the box is greyed out.
RendererChooses how the picture is drawn. The choices are Hardware (OpenGL), Hardware (Vulkan). The default is Hardware (Vulkan). A Hardware choice uses your graphics card. It is fast, but the picture is drawn outside the savestate, so video can differ on another computer. A warning appears under the box when you pick one.

A link at the bottom takes you to the Chimera issue page, for reporting problems and asking for features. If no core is installed, Next shows a message asking you to pick one.

Page 2 Add your files

This page asks for the game files and other data. The core decides what appears here. Vita3K shows 3 groups of files. Hover over a group to see the core's own help text.

GroupHow manyFile typesWhat it is for
GameExactly one.vpk, .zip, .pkgThe game, in one of three forms. It can be a .vpk file. It can be a NoNpDRM dump packed as a .zip (the game's folder, including its sce_sys/package/work.bin). Or it can be a PlayStation Store package (.pkg), with the game's licence in the Licence slot. Vita3K installs it into the machine before it starts. Vita3K's compatibility list (vita3k.org/compatibility) says which games work.
LicenceAt most one.bin, .rifShown when the file under Game ends in .pkg.
The licence that decrypts a .pkg game. It is either the game's work.bin (the 512-byte file a NoNpDRM dump keeps in sce_sys/package) or the console's own .rif file for the game. A package is encrypted and installs nothing without it. A .vpk or a .zip dump needs none, because a dump includes its own. The project and the movie record exactly which file was used, as they do for the game.
Save dataAt most one.zipWhat the game already saved, as Emulator > Export Save Data... wrote it. It is a .zip with savedata/<TITLE ID>/... (the system's save data) and data/... (where homebrew keeps its files). A save copied from a Vita with ux0 - /user/00/ in front of the path, or a plain <TITLE ID>/ folder, is accepted too. It is put into the machine before the game starts.

Controls in each group

  • Add opens a file picker titled Add to and the group name. It starts in the ROM folder set under Config, Paths. It filters to the group's file types, and you can switch it to All files. You can select several files at once.
  • Remove takes the selected row out of the list. It does not delete the file on disk.
  • Drag and drop works on each list. A file you drop lands in the group you drop it on. Folders are ignored.

Rules

  • Groups whose How many is Exactly one or At least one need a file. These are Game. Next will not continue until each has a file.
  • Each group's title shows how many files it takes and the file types it expects. A file with another extension is still added, and a message at the bottom tells you it is not what the group expects.
  • Adding a file with the same name as one already in the group does nothing.
  • A group is greyed out when its condition is not met. The description of the group starts with that condition in italics.

Starting from a dropped file

If you drag a file onto the main Chimera window, the wizard opens with the core that claims the file's extension already chosen. The file goes into the first group that lists that extension. Vita3K claims .vpk.

Page 3 Set up the machine

This page asks for the emulation settings. Every setting here shapes the emulated machine, and the project records each one at the value you leave it on. A recording made with a project only plays back correctly with the same settings.

Settings

The grid lists the settings alphabetically. Click a row to read its description in the pane under the grid. A value that differs from the default is shown in bold. Right-click a row and choose Reset to put the default back. True or False settings and settings with a fixed set of choices are picked from a list. Number and text settings are typed in. The System and Renderer are not in the grid because Page 1 already asked for them. Vita3K has 8 settings in the grid. All of them are always shown.

SettingAllowed valuesDefaultWhat it does
Clock at Power-On1262304000 to 21459168001356998400The date the console's clock shows when the game starts, in seconds since 1970. For example 1356998400 is 2013-01-01. After the start the clock runs with the emulated console and never with your computer. It is part of the machine. A game that picks its random numbers from the time plays differently with another date.
CPU Clock (MHz)333 to 40001332How fast the console's processor runs. The game's code uses up emulated time at this speed. The default, 1332, is the Vita's three 444 MHz processor cores added together, counted at one instruction per cycle. It is part of the machine.
Enter Buttoncross, circlecrossWhich button confirms in the system's dialogs and in games that follow the system setting. It is Cross outside Japan and Circle on Japanese consoles. Games read it, so it is part of the machine.
Internal Resolution1x, 2x, 3x, 4x1xHow many times the Vita's 960x544 resolution the graphics card draws at (Vita3K's Internal Resolution Upscaling). Above 1x the picture Chimera shows and records is the larger one, for example 1920x1088 at 2x. 3D shapes get finer edges. Text and images made for 960x544 are only enlarged. It is part of the machine. What the graphics card draws is written back into the Vita's memory at the Vita's own size, reduced from the larger picture, so those bytes differ from the ones a 1x picture leaves, and a game that reads its own picture can tell the difference. Measured on Alien Breed (1500 frames) and Alien Shooter (300 frames), the machine's timing, its thread switches and its sound are the same at 2x as at 1x. One limit - a savestate holds the picture at 960x544 and not the larger one, so in the first frame after a state is loaded the picture can be the small one enlarged. The machine itself is the same, and a movie played from the start is drawn at the chosen size throughout. Choose the resolution when the project is made, because an existing movie does not fit another resolution. Higher resolutions need more graphics power - 4x has sixteen times the pixels of 1x.
NGS Audioon, offonVita3K's 'Enable NGS Support' option. NGS is the Vita's sound library for games that mix their own sound. With it on, the core runs the library and those games have their sound. With it off, every NGS call returns at once without doing anything, and a game that uses NGS is silent or misses some sounds. It is on unless you turn it off here. Turn it off only for a game that hangs or crashes inside NGS, because Vita3K's NGS is not complete. What a game gets back from the library affects its timing (a game may wait for a sound to end), so it is part of the machine and a movie made with it off needs it off.
Rendering Accuracystandard, highstandardVita3K's 'High Accuracy' option, for the Vulkan renderer. With "standard", Vita3K's own default, the renderer takes two shortcuts that are faster and right in most games. With "high" it takes neither - a game that reads back what it has just drawn gets exactly that, and textures are sampled the exact way. Some games' pictures are only right with "high". It is slower, and needs a graphics driver that has the 'fragment shader interlock' feature for the first of the two (without it only the second changes). The OpenGL renderer does not read this setting. The two values do not draw every pixel alike, so a movie should be played back with the one it was made with if its pictures are to match.
System Language
20 choicesjapanese, english-us, french, spanish, german, italian, dutch, portuguese-pt, russian, korean, chinese-traditional, chinese-simplified, finnish, swedish, danish, norwegian, polish, portuguese-br, english-gb, turkish
english-usThe console's system language. Games read it to choose their language, so it is part of the machine.
System Softwarefull, fonts, nonefullWhich of the Vita's system files are installed in the machine. Most games need the system software (PSVUPDAT.PUP, from PlayStation's update page) for its system libraries, and the font package (PSP2UPDAT.PUP) for the system fonts. 'Full' installs both. 'Fonts' installs only the font package. 'None' is for homebrew built with the Vita SDK, which needs neither. They are installed before the game starts, so they are part of the machine.

Page 4 Provide firmware

This page asks where to find the firmware files your choices need. It only appears when at least one setting calls for a file. With some settings it is skipped, and the page before it ends with Create instead of Next. The list changes when you go back and change a setting.

The list

Each row shows the firmware name, the file name the core expects, its SHA1 and its status. The status reads "found" followed by a file name, "your own" followed by a file name, "not found", or "optional - core default used". A green row has a file and a red row does not. Hover over a row to read what the file is for.

Chimera looks in the Firmware folder first. That folder is set under Config, Paths and is called Firmware beside Chimera.exe by default. It also looks at files you chose for this core before. A file it finds is matched by its SHA1, so its name does not matter.

Buttons

  • Select File picks a file for the selected row. Double-clicking a row does the same. It works even when a file was already found. If the row shows a SHA1, the file must match it, or the wizard refuses the file and shows the SHA1 it found. A row that shows "(your own file)" has no fixed SHA1, so any file is accepted and its SHA1 is recorded.
  • Clear removes the file chosen for the selected row.
  • Scan Folder searches a folder you pick and fills every row it can. The folder picker has an Include sub-folders box, ticked by default. Turn it off for a very large folder. A row with a SHA1 takes only the exact file. A row with no SHA1 takes the file with the expected name. A message at the bottom says how many files were scanned and how many rows were filled.

Create stays greyed out until every row that is not optional has a file.

Which files can be asked for

Vita3K can ask for up to 2 files. Only the rows your choices call for appear. A description that starts with an italic condition is only asked for in that case.

FirmwareExpected fileSHA1What it is
PS Vita system software (PSVUPDAT.PUP)PSVUPDAT.PUP(your own file)Asked for when System Software is full.
The Vita's system software update, as PlayStation publishes it. Vita3K installs it before the game starts. The system libraries most games load come from it.
PS Vita font package (PSP2UPDAT.PUP)PSP2UPDAT.PUP(your own file)Asked for when System Software is one of full, fonts.
The Vita's font package. Vita3K installs it before the game starts. Games that draw text with the system fonts need it.

Create the project

On the last page the Next button reads Create. Chimera then reads every file you added, which can take a while for large files, and checks them against the core's rules. If a file is refused, the wizard goes back to Page 2 and says why. If all is well, the wizard closes and the project opens in TAStudio at the first frame, which is the first picture the game draws.

Some cores add a page that compiles the game's code before the project is made. Vita3K does not, so you will not see it.

A project's settings cannot be edited once it exists, because a changed setting is a different machine. To change one, choose New Chimera Project again. The wizard opens filled in with your last answers, so you change that one setting and go through the pages to Create again.
