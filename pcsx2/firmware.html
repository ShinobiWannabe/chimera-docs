About this data

77 firmware entries, 85 rows. A rule that does not depend on the machine gets one row marked 'All machines'. A rule that does is repeated for each machine it can apply to. 'Also required only when' holds the part of the rule that still depends on another setting or on a file slot. Label is the firmware's own label and is empty when the config gives none. An empty rule means the file is always needed. Entries marked [Optional] can be skipped. A size of 0 means any size is fine.
