Region From The Gametrue, falsetrueTakes the console's region from the game's disc. Turn it off to use the region set below, for a disc that names several regions or the wrong one. It is part of the machine, so a movie needs the same value.
Region (Sega Saturn)jp, na, eu, kr, tw, as, br, lajpThe console's region when it is not taken from the game: jp is Japan, na North America, eu Europe, kr Korea, tw Taiwan, as Asia, br Brazil, la Latin America. Japan and Taiwan use the Japanese BIOS file and the others the North American and European one. It is part of the machine, so a movie needs the same value.
Cartridgeauto, none, backup, extram1, extram4, cs1ram16, ar4mpautoWhat is in the cartridge slot. 'auto' picks what the game is known to need and the backup memory cartridge otherwise. 'backup' is a memory cartridge for saves, 'extram1' and 'extram4' are the 1 MB and 4 MB RAM cartridges some games require, 'cs1ram16' is a 16 MB RAM cartridge for homebrew, and 'ar4mp' is the Action Replay 4M Plus, which needs its own ROM file. It is part of the machine, so a movie needs the same value.
Cartridge When The Game Needs Nonenone, backup, extram1, extram4, cs1ram16, ar4mpbackupThe cartridge that 'auto' plugs in for a game that is not known to need one. It is part of the machine, so a movie needs the same value.

Starting Clock0 to 2147483647946684800What the machine's clock shows when it is switched on, in seconds since 1970 (Unix time). The Saturn's clock and the ST-V's are set from it. This is a setting, and not your computer's clock, so that a movie plays back the same on any day.
Processor Emulation (Virtual Boy)fast, accuratefastHow closely the processor's timing is followed. 'accurate' counts every step and a few games need it. 'fast' is Mednafen's default. It is part of the machine, so a movie needs the same value.
Read The Pad At Oncetrue, falsetrueGives the game the pad's buttons at the moment it asks for them and not after the console's real delay of a frame. It is Mednafen's default. It is part of the machine, so a movie needs the same value.
Show The Frame At Oncetrue, falsefalseShows a frame as soon as it is drawn and not when the console's displays would light it. It changes which frame a picture belongs to, so a movie needs the same value.
How The Two Eyes Are Shownanaglyph, cscope, sidebyside, vli, hli, left, rightanaglyphThe console shows a picture to each eye. 'anaglyph' puts both on one picture in two colours for coloured glasses, 'sidebyside' puts them next to each other, 'cscope' is the layout of a CyberScope viewer, 'vli' and 'hli' weave them line by line, and 'left' and 'right' show one eye only. It changes the picture only.

About this data

59 settings, 69 rows. There is one row for each machine and each option. A setting for several machines is repeated for each machine. A setting with no rule is listed under every machine as 'Always shown'. Origin says where the setting came from.
