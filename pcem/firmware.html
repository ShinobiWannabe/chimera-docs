About this data

217 firmware entries, 217 rows. 'Also required only when' holds the part of the rule that still depends on another setting or on a file slot. Label is the firmware's own label and is empty when the config gives none. An empty rule means the file is always needed. Entries marked [Optional] can be skipped. A size of 0 means any size is fine.

Rows are grouped by file name. When more than one hash, size or other value is accepted for a file name, the first one is shown and a button such as +3 shows the rest.
